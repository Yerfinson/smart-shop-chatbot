# Context

## Qué es este proyecto
Smart Shop Chatbot es una landing page para tienda online con un chatbot 
integrado powered by Gemini API. El objetivo es demostrar habilidades de 
integración de IA en aplicaciones web reales.

## Para quién es
Tiendas online pequeñas y medianas que quieren automatizar la atención 
al cliente con IA sin costos elevados.

## Qué problema resuelve
Los dueños de tiendas no pueden responder mensajes 24/7. El chatbot 
responde preguntas frecuentes automáticamente sobre productos, precios, 
horarios y métodos de pago.

## Stack
- Frontend: Angular 18 standalone components
- Backend: Node.js + Express
- IA: Gemini API (gemini-2.0-flash)
- Estilos: TailwindCSS
