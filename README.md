# Smart Shop Chatbot

Landing page para tienda online con chatbot de IA integrado que responde 
preguntas sobre productos, precios y pedidos de forma automática 24/7.

## Stack
- **Frontend:** Angular 18 + TailwindCSS
- **Backend:** Node.js + Express + TypeScript
- **IA:** Gemini API (gemini-2.0-flash)

## Funcionalidades
- Landing page responsive con secciones: hero, productos, sobre nosotros, contacto
- Chatbot flotante con contexto de la tienda
- Historial de conversación por sesión
- Respuestas automáticas sobre productos, precios y métodos de pago

## Instalación

### Backend
```bash
cd backend
npm install
cp .env.example .env  # agrega tu GEMINI_API_KEY
npm run dev
```

### Frontend
```bash
cd frontend
npm install
ng serve
```
